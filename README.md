# BankDash (React + Tailwind)

    npm install
    npm run dev

Theme: deep teal (`brand`) + coral (`coral`) + gold + sky on a mist background. Edit colors in `tailwind.config.js` and chart colors in `src/theme.js`.

- `src/App.jsx` – routing only
- `src/layouts/` – DashboardLayout (sidebar drawer on mobile)
- `src/pages/` – one file per screen (My Privileges uses ComingSoonPage — no design was provided)
- `src/components/{layout,ui,cards,charts,features}` – reusable pieces
- `src/data/mockData.js` – all sample data
